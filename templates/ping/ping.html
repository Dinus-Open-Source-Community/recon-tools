Ping adalah tool network diagnostic yang menggunakan ICMP protocol untuk:

  • Test konektivitas jaringan
  • Mengukur latency (waktu respons)
  • Mendeteksi packet loss
  • Memeriksa status host/device
📋 Parameter Ping
Count: Jumlah packet ICMP yang dikirim
Timeout: Waktu tunggu maksimal untuk setiap respons (detik)
Target: Domain name atau IP address tujuan
