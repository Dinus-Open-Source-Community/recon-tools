ℹ️ Apa itu WHOIS?

WHOIS adalah protokol query dan response yang banyak digunakan untuk menanyakan database yang menyimpan data pengguna terdaftar atau sumber daya internet, seperti nama domain, blok alamat IP, atau otonom sistem.

Dengan tool ini, Anda dapat melihat informasi tentang:

  • 📋 Registrar domain
  • 📅 Tanggal pendaftaran dan kedaluwarsa
  • 🌐 Name servers
  • 📊 Status domain
  • 📧 Informasi kontak (jika tersedia)
